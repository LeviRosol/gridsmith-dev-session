# GridSmith Lunch & Learn

## Preview

1. Open `slides.md` in VS Code.
2. Open the Command Palette.
3. Choose **Marp: Open Preview to the Side**.

The workspace setting loads the custom GridSmith theme and permits the HTML
used for the layouts.

## Editing

- Replace visible placeholder boxes as screenshots and photos become available.
- Presenter notes live in HTML comments below each slide.
- Each `---` starts a slide.
- Hide or remove the final screenshot-checklist slide before presenting.

## Export

Choose **Marp: Export Slide Deck** from the Command Palette. HTML is ideal for
presenting; PDF makes a dependable backup.
